기존 교안과 7개 실습을 유지하면서 내부 동작 설명, 상태 그림, 상세 복구 훈련을 추가한다.

## 시간 운영
기존 4시간에 복구 전 범위를 몰아넣지 않는다.
- 1시간: 상태와 작은 커밋, 세 영역 그림과 staged 사례
- 2시간: branch/HEAD, 미커밋 이동과 공유 여부 구분
- 3시간: 원격·PR, fetch와 원격 참조, 정상 협업
- 4시간: 같은 줄 충돌, 중단 조건, 공유 취소와 보안 경계
- 이후: 10~15분 반복 훈련 8회 정도를 운영 초안으로 사용
- 복합 문제: 20~30분 별도 확보, 실제 속도에 따라 조정
시간 수치는 운영 제안이지 실제 학급 측정 결과가 아니다.

## 반복 순서
1. staged 범위 선택
2. branch 전환 거절과 임시 보관
3. 미공유 main 커밋 보존
4. 양쪽 분기 + 미완성 작업 동기화
5. 내용 충돌·abort·삭제/수정 판단
6. revert와 분실 커밋 복구
7. PR 기준·리뷰·파일 규칙
8. 조건을 바꾼 복합 문제
정답 제출은 요구하지 않는다. 실제 화면과 설명으로 확인한다.

## 완료 기준
- 기존 내용과 추가 실습이 양방향으로 연결됨
- 각 핵심 복구 단원에 원리, 그림, 재현, 진단, 선택, 복구, 검증, 중단 조건 존재
- 실습 스크립트는 새 임시 폴더만 생성하고 학생 저장소를 삭제/초기화하지 않음
- 9개 실습 복구 테스트 성공, 링크와 SVG 구조 검증
- 공유 이력·비밀정보에 단독 처리 경계 표시
- 기술 리허설과 실제 학생·GitHub 협업 검증을 구분
- main 병합 전 사용자 승인

## 비범위
모든 Git 내부 객체 형식의 암기, 고급 rebase/역사 전체 정리 실습, 실제 자격 증명 노출,
GitHub 보호 규칙의 자동 변경, 실제 원격 branch 강제 갱신은 포함하지 않는다.

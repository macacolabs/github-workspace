작업과 브랜치 상황

not a git repository

확인 Get-Location, git rev-parse --show-toplevel

대응 기존 프로젝트면 저장소 폴더로 이동합니다. 새 프로젝트일 때만 git init합니다.

중단 상위·하위 폴더에 init을 반복하지 않습니다.

관계없는 파일까지 stage됨

git diff --staged
git restore --staged path/to/file
git add path/to/needed-file

작업 파일은 그대로 두고 commit 대상에서만 제외합니다.

main에서 미commit 작업

git status
git switch -c feature/payment-docs
git status

새 branch로 이동한 뒤 변경이 보존됐는지 확인합니다.

main에 이미 로컬 commit

push 여부와 hash를 확인한 뒤 먼저 commit을 가리킬 rescue branch를 만듭니다.

git switch -c feature/rescue-main-work
git log --oneline -3

중단 branch를 만들기 전에 reset하지 않습니다.

branch 전환 거절

완성 단위면 commit, 급한 임시 이동이면 이름 있는 stash를 사용합니다.

git stash push -m "WIP: payment validation"
git switch hotfix/login
git stash list

detached HEAD에서 작업

git status
git log --oneline -5
git switch -c rescue/detached-work

이동하기 전 현재 commit에 branch 이름을 붙입니다.

10분 훈련

main에서 파일을 수정하고 파일을 잃지 않은 채 feature branch로 이동합니다. 전후 status와 log --all로 성공을 설명합니다.

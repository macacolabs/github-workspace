충돌 상황

충돌 해결은 marker 삭제가 아니라 두 변경의 의도를 확인해 최종 결과를 결정하는 작업입니다.

공통 절차

  1. status에서 충돌 종류와 파일을 확인합니다.
  2. 양쪽 변경의 목적과 담당자를 확인합니다.
  3. 최종 내용을 편집하고 marker를 제거합니다.
  4. add 후 빌드·테스트·실행합니다.
  5. commit 후 clean 상태를 확인합니다.
git status
git diff
rg "^(<<<<<<<|=======|>>>>>>>)"
git add path/to/resolved-file
git commit

같은 줄 충돌

한쪽을 기계적으로 고르지 말고 요구사항에 맞는 최종 내용을 작성합니다.

modify/delete

파일 필요 여부를 담당자와 결정합니다. 유지면 add, 삭제면 git rm으로 기록합니다.

add/add

내용을 합치거나 역할별 이름으로 분리하고 import와 링크를 검증합니다.

병합 중단

git status
git merge --abort
git status

시작 전 변경이 있었다면 보존 여부부터 확인합니다.

lock 파일

manifest 의도를 합의하고 같은 패키지 도구 버전으로 재생성합니다. 숫자를 손으로 합치지 않습니다.

binary 파일

파일 소유자와 기준본을 정하고 필요하면 양쪽을 다른 이름으로 보존합니다.

원격과 인증 상황

push 전에 관계 읽기

git remote -v
git fetch origin
git status -sb
git branch -vv
git log --oneline --graph --decorate --all -12

fetch는 원격 상태를 가져오지만 작업 파일을 바로 합치지 않습니다.

첫 push에 upstream 없음

git branch --show-current
git push -u origin feature/profile-card

main으로 바꿔 push하지 않습니다.

push rejected / non-fast-forward

원격에 로컬이 모르는 commit이 있습니다. fetch 후 graph와 diff를 보고 팀 방식으로 통합·테스트한 뒤 push합니다.

중단 force push로 원격 commit을 덮지 않습니다.

ahead / behind / diverged

표시뜻행동
ahead로컬에만 commitpush 대상과 diff 확인
behind원격에만 commitfetch 후 원격 log 확인
diverged양쪽에 다른 commitgraph 후 통합 방식 합의

Repository not found / 권한 없음

  1. remote URL의 소유자와 저장소명을 확인합니다.
  2. 브라우저에서 URL과 초대 수락을 확인합니다.
  3. Credential Manager의 로그인 계정을 확인합니다.

토큰을 URL·채팅에 붙이지 않습니다.

원격 branch만 존재

git fetch origin
git branch -a
git switch --track origin/feature/profile-card

삭제된 원격 branch가 보임

팀원이 사용하지 않는지 확인한 뒤 git fetch --prune으로 정리합니다.

프로젝트 Git
상황 대응 사전

명령어 목록이 아니라 증상으로 찾아가는 현장 안내서입니다. 오류 원문과 현재 상태를 확인하고, 변경을 보존하는 가장 작은 조치를 선택합니다.

42개 상황제출 없음프로젝트 중 상시 사용

막혔을 때 60초

  1. 멈춤: reset, clean, force를 실행하지 않습니다.
  2. 목표: 원래 하려던 일을 한 문장으로 말합니다.
  3. 보존: 사라지면 안 되는 파일과 commit을 확인합니다.
  4. 상태: branch, status, diff, graph 중 필요한 것을 봅니다.
  5. 조치: 아래 증상 분류로 이동합니다.
  6. 검증: 같은 확인 명령과 프로젝트 테스트로 결과를 확인합니다.
git branch --show-current
git status
git diff
git diff --staged
git log --oneline --graph --decorate --all -12

PULL REQUEST · TEAM

잘못된 base, 섞인 commit, 리뷰, 보호 규칙

RECOVERY · SECURITY · WINDOWS

복구·파일·보안

revert, reflog, stash, secret, LFS, CRLF

도움을 요청할 때 말할 5가지

  1. 하려던 일
  2. 오류 원문 전체
  3. 현재 branch와 git status
  4. 이미 실행한 명령
  5. 반드시 보존해야 하는 변경

채팅에 넣지 않는 것

토큰, 비밀번호, 개인키, .env 내용은 화면 공유·채팅·이슈에 붙이지 않습니다.

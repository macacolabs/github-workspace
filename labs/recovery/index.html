프로젝트에서 판단하고 복구하기

기존 7개 실습에서 배운 흐름을, 조건이 달라져도 스스로 선택하는 단계로 확장합니다. 명령을 외우기 전에 현재 상태와 보존할 작업부터 확인합니다.

읽기와 실습을 함께 진행하세요

  1. 내부 원리를 그림으로 읽습니다.
  2. 문제가 들어 있는 새 연습 저장소를 만듭니다.
  3. 해결 절차를 펼치기 전에 진단과 선택 이유를 말합니다.
  4. 명령 결과뿐 아니라 파일 내용과 이력도 검증합니다.
  5. 변형 문제에서는 명령 안내 없이 다시 수행합니다.
이 과정은 4시간 수업 전체에 추가로 몰아넣는 내용이 아닙니다. 기본 개념은 기존 시간에 통합하고, 복구 연습은 이후 프로젝트 시간에 나누어 반복합니다.

연습 환경 준비

Git과 Python이 필요합니다. 수업자료 저장소 루트에서 버전을 확인하세요. Python이 없으면 강사가 준비한 환경을 사용합니다. Git 계정이나 실제 비밀정보는 필요하지 않습니다.

git --version
python --version
python scripts/recovery_lab.py staged

명령이 출력한 Set-Location 줄을 실행하면 임시 연습 폴더로 이동합니다. 시나리오마다 새 폴더를 만들기 때문에 실제 작업을 지우거나 덮지 않습니다. 같은 문제를 다시 만들 때도 기존 연습 폴더를 삭제하지 않습니다.

모드재현되는 상태
stagedadd 후 재수정 + 관계없는 stage + 미추적 파일
branch / committed전환 거절 / main에 잘못한 로컬 커밋
remote두 PC 역할과 bare 원격, 분기된 이력 + 미커밋 변경
conflict / delete-conflict같은 줄 / 삭제와 수정의 충돌
stash / lost / shared임시 보관 / detached 커밋 분실 / 공유 취소 판단

GitHub PR·권한·승인 실습은 별도의 수업용 GitHub 저장소에서 진행합니다. 로컬 원격 실습만 통과했다고 GitHub 협업을 검증한 것은 아닙니다.

# Team Profile

이 저장소는 Git 상태, 기능 브랜치, Pull Request, 충돌 해결을 연습하는 성장형 실습입니다.

## 팀 목표

아래 문장을 팀이 합의한 내용으로 완성하세요.

> 우리 팀은 ____________________ 서비스를 만듭니다.

## 학생 작업

1. 자신의 이름으로 기능 브랜치를 만듭니다.
2. members/이름.md를 작성합니다.
3. src/HelloTeam.java의 출력 내용을 한 가지 수정합니다.
4. 변경 목적별로 커밋을 나눕니다.
5. Pull Request에서 목적·변경·검증을 설명합니다.

완성 예시나 정답은 이 starter에 포함하지 않습니다.

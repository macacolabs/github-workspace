프로젝트에서 막히지 않는
Git 실습 과정

설명을 읽는 과정이 아닙니다. 하나의 저장소를 계속 발전시키며 상태 확인, 기능 브랜치, 원격 동기화, 충돌, PR 리뷰, 장애 대응을 직접 수행합니다.

7개 실습 모듈2인 협업실패 재현실행 확인종합평가

수행 방법

1. 먼저 예측

명령 실행 뒤 브랜치와 파일 상태가 어떻게 바뀔지 먼저 예상합니다.

2. 실행하고 관찰

status, diff, log로 예상과 실제 결과를 비교합니다.

3. 실패와 복구

정해진 오류를 직접 만들고 데이터 손실 없이 복구합니다.

4. 실행 결과와 설명

명령 결과, 커밋 해시, PR URL, 판단 근거를 말로 설명합니다.

MODULE 01

상태와 작은 커밋

필요한 변경만 stage하고 목적별 커밋을 만듭니다.

MODULE 02

기능 브랜치

최신 main에서 브랜치를 만들고 이력을 읽습니다.

MODULE 03

원격 동기화

origin, fetch, pull, push와 push 거절을 다룹니다.

MODULE 04

2인 충돌 해결

같은 줄 충돌을 만들고 합의·검증 후 해결합니다.

MODULE 05

Pull Request 협업

목적·변경·검증을 설명하고 리뷰를 반영합니다.

MODULE 06

장애 대응 훈련

잘못된 stage, 브랜치, push 오류를 진단합니다.

MODULE 07

프로젝트 준비도 평가

안내 없이 전체 협업 흐름을 수행하고 설명합니다.
